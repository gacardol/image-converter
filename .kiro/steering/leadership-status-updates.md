# Leadership Status Updates

## When to Use
- **Weekly**: Friday EOD or Monday morning update to your manager
- **Ad-hoc**: When leadership asks "how are things going?" or requests a quick status
- **Standup**: Daily or bi-weekly team sync talking points
- **Escalation**: When you need leadership help unblocking something

Always keep these short and scannable. Leadership doesn't want a novel — they want signal.

---

## Weekly Status Update (Slack / Email)

Best for: Friday EOD recap or Monday morning kickoff message to your manager.

```
📊 **Weekly Status — [DATE RANGE]**

**Launches**: [X] sellers launched this week ([NAMES if notable])
**Pipeline**: [X] BD | [X] Evaluation | [X] Closed Won
**Outreach**: [X] sellers contacted, [X] onboarding calls completed
**Activation**: [X] sellers activated [LEVER] this week

**Wins** 🟢
- [Specific win with numbers]
- [Second win]

**Blockers / Risks** 🔴
- [Issue + what you need]

**Focus Next Week**
- [Priority 1]
- [Priority 2]
```

### Example (filled in)

```
📊 **Weekly Status — Apr 28 – May 2**

**Launches**: 4 sellers launched (Loja TechBR, Casa Verde SP, ModaFit, Eletrônicos Plus)
**Pipeline**: 18 BD | 12 Evaluation | 4 Closed Won this week
**Outreach**: 52 sellers contacted, 8 onboarding calls completed
**Activation**: 3 sellers activated Ads, 2 activated Automated Pricing

**Wins** 🟢
- 4 launches vs. 3 target — ahead of pace
- ModaFit activated Ads + Coupons in first week post-launch

**Blockers / Risks** 🔴
- 3 sellers stuck in category approval (Electronics) for 10+ days — need escalation

**Focus Next Week**
- Close 5 Evaluation → Launched
- Batch outreach to 40 new Meli Badge sellers
```

## Quick Status (When Asked on the Spot)

For when your manager pings you with "how's it going?" or "quick update?"

```
This week: [X] launched, [X] in pipeline, on track for [monthly target].
Main win: [one-liner].
Main risk: [one-liner].
Need help with: [one-liner or "nothing right now"].
```

### Example

```
This week: 4 launched, 30 active in pipeline, on track for 18 launches this month.
Main win: Converted 3 Meli Badge sellers in one week.
Main risk: Category approval delays in Electronics — 3 sellers waiting 10+ days.
Need help with: Escalation path for category approvals.
```

## Standup / Team Sync Talking Points

For daily or bi-weekly team syncs. Keep to 60 seconds.

```
**Done since last sync:**
- [Key accomplishment 1]
- [Key accomplishment 2]

**Doing today / this week:**
- [Priority 1]
- [Priority 2]

**Blocked on:**
- [Blocker or "nothing"]
```

## Escalation Update

When you need leadership to act on something. Be specific about the ask.

```
🚨 **Escalation: [TOPIC]**

**Situation**: [What's happening — 1-2 sentences]
**Impact**: [How many sellers affected, revenue at risk, timeline pressure]
**What I've tried**: [Actions already taken]
**Ask**: [Exactly what you need from leadership]
**Deadline**: [When this needs to be resolved by]
```

### Example

```
🚨 **Escalation: Category Approval Delays — Electronics**

**Situation**: 3 sellers in Evaluation stage have been waiting 10+ days for Electronics category approval. No response from category team.
**Impact**: 3 sellers at risk of churning — they're actively selling on Mercado Livre and losing patience. ~R$15K estimated monthly GMV at risk.
**What I've tried**: Submitted tickets via SIM, followed up twice, pinged category team Slack channel.
**Ask**: Can you escalate to category team leadership or provide an alternative approval path?
**Deadline**: Need resolution by Friday or sellers will likely disengage.
```

Keep this updated throughout the month. Share with manager mid-month and end-of-month.

## End-of-Month Summary (for Manager 1:1)

Slightly more detailed than weekly, less formal than the full monthly report. Good for your 1:1 with your manager.

```
## [MONTH] Recap

**Results vs. Target**
- Launches: [X] / [TARGET] ([%])
- Pipeline health: [X] active opportunities
- Growth lever activations: [X] total ([breakdown by lever])

**What Went Well**
- [Specific win 1]
- [Specific win 2]

**What Didn't Go Well**
- [Challenge 1 — what happened and what you learned]

**What I Need**
- [Support ask 1]
- [Development/learning ask]

**Next Month Focus**
- [Priority 1]
- [Priority 2]
```

## Writing Tips for Status Updates
- **Lead with numbers** — "4 sellers launched" not "had a good week"
- **Be specific** — seller names, dates, amounts when possible
- **Red flags early** — don't bury bad news at the bottom
- **Always include the ask** — if you need help, say exactly what you need
- **Keep it scannable** — bullets and bold, not paragraphs
- **Consistent cadence** — send at the same time each week so leadership expects it
