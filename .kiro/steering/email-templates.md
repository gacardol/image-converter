# Email & WhatsApp Templates

## How to Use
When the user asks to "draft an email", "write outreach", or "send follow-up", use these templates as a starting point. Always personalize with seller name, store name, category, and relevant growth lever.

All seller-facing content should be in **Brazilian Portuguese** unless told otherwise.

---

## 1. First Outreach — New Seller (Email)

**Subject**: Bem-vindo(a) à Amazon.com.br — Vamos lançar seu primeiro produto!

```
Olá [NOME DO VENDEDOR],

Meu nome é Gabriel, sou Account Manager na Amazon Brasil e estou aqui para ajudar você a ter sucesso na Amazon.com.br.

Vi que você se cadastrou recentemente e gostaria de agendar uma conversa rápida (15-20 min) para:

✅ Ajudar com o cadastro do seu primeiro produto
✅ Explicar as ferramentas que vão impulsionar suas vendas
✅ Tirar qualquer dúvida sobre a plataforma

Você teria disponibilidade esta semana para uma ligação?

Abraço,
Gabriel Cardoso
Account Manager — Amazon Brasil
```

## 6. Growth Lever Activation — Ads (Email)

**Subject**: Aumente suas vendas com Produtos Patrocinados 🚀

```
Olá [NOME DO VENDEDOR],

Parabéns pelo progresso na Amazon.com.br! Vi que você já tem [X] produtos listados e está no caminho certo.

O próximo passo para acelerar suas vendas é ativar os **Produtos Patrocinados (Ads)**. Vendedores que usam Ads têm em média 30% mais visibilidade nos resultados de busca.

**Como começar:**
1. Acesse Seller Central → Publicidade → Gerenciador de Campanhas
2. Clique em "Criar campanha" → Produtos Patrocinados
3. Selecione seus produtos com melhor desempenho
4. Defina um orçamento diário inicial de R$ [VALOR SUGERIDO]

Posso agendar uma ligação rápida para configurar juntos?

Abraço,
Gabriel Cardoso
```

## 7. Growth Lever Activation — FBA (Email)

**Subject**: Entrega mais rápida = mais vendas — Conheça o FBA

```
Olá [NOME DO VENDEDOR],

Quero apresentar o **Fulfillment by Amazon (FBA)** — nosso serviço de logística que pode transformar suas vendas.

**Benefícios do FBA:**
✅ Entrega rápida para o cliente (selo Prime)
✅ Maior chance de ganhar o Buy Box
✅ Amazon cuida do armazenamento, embalagem e envio
✅ Atendimento ao cliente incluído

**Próximos passos para ativar:**
1. Acesse Seller Central → Inventário → Gerenciar inventário FBA
2. Selecione os produtos que deseja enviar
3. Crie um plano de envio para o centro de distribuição

Quer que eu explique melhor em uma ligação rápida?

Abraço,
Gabriel Cardoso
```
