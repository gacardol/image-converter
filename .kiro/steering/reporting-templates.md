## Metrics Definitions

| Metric | Definition | Source |
|--------|-----------|--------|
| Sellers contacted | Unique sellers who received outreach email/WhatsApp | Outlook/manual tracking |
| Onboarding calls | Completed calls (not scheduled, completed) | Calendar/Astro |
| Sellers launched | Sellers with first product live and buyable | QuickSight Sales Hub |
| Growth lever activation | Sellers who activated Ads/FBA/Coupons/etc. | QuickSight Sales Hub |
| Pipeline stage | Current Astro opportunity stage | Astro |
| Response rate | % of contacted sellers who responded | Manual tracking |
| Time to first listing | Days from registration to first live product | QuickSight |

## Data Pull Checklist (Monthly)

Before compiling the report:
- [ ] Refresh QuickSight Sales Hub 1.0 — note date/time of data
- [ ] Refresh QuickSight Sales Hub 2.0 — note date/time of data
- [ ] Pull Scorecard data — note date/time
- [ ] Export Astro pipeline snapshot
- [ ] Cross-check numbers between sources for consistency
- [ ] Flag any data discrepancies before including in report

## Report Quality Checklist
- [ ] All numbers are sourced and dated
- [ ] MoM comparisons are accurate (same date ranges)
- [ ] Highlights and lowlights have specific numbers, not vague statements
- [ ] Action items are specific and have owners/deadlines
- [ ] Seller names/stores used instead of IDs where possible
- [ ] Report tells a story: what happened → why → what's next
