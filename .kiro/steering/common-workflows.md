# Common Workflows

## Daily Routines
- **Morning pipeline check**: Review Astro opportunities, identify sellers needing follow-up
- **Email batch**: Draft and send outreach emails to new sellers or follow-ups
- **Dashboard review**: Check QuickSight Sales Hub for seller performance changes
- **Slack catch-up**: Review team channels for updates, escalations, or asks

## Seller Lifecycle Workflows

### 1. Mass Outreach (New Sellers)
- Draft email templates in Portuguese for seller segments
- Personalize with seller name, category, and relevant growth levers
- Track which sellers responded vs. need follow-up

### 2. Onboarding Call Prep
- Pull seller info from Astro opportunity
- Check if seller has existing listings or is brand new
- Prepare talking points: first product launch steps, FBA benefits, pricing tools

### 3. Growth Activation
- Identify sellers ready for next lever: Ads → Coupons → FBA → Brand Registry → Automated Pricing
- Draft activation emails with specific instructions for each lever
- Track activation status in pipeline

### 4. Pipeline Management (Astro)
- Move opportunities through stages: BD → Evaluation → Closed Won
- Update opportunity notes after each seller interaction
- Flag stalled opportunities for escalation

### 5. Monthly Reporting
- Pull data from QuickSight dashboards (Sales Hub 1.0/2.0, Scorecard)
- Compile seller performance metrics
- Format leadership report with highlights, lowlights, and trends

## Quick Commands
- "Draft outreach email for [seller]" — generates Portuguese email template
- "Prep onboarding call for [seller]" — pulls context and creates talking points
- "Pipeline update" — summarizes current Astro pipeline status
- "Monthly report draft" — starts compiling performance data
- "End of session" — saves current work context for next time
