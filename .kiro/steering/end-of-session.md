# End of Session Process

When the user says "end of session", "save session", or "wrap up":

1. Review the full conversation
2. Update `tracking/last-session-context.md` with:
   - Date and summary of work done
   - Specific sellers, accounts, or opportunities discussed
   - Pipeline changes or status updates made
   - Pending action items and next steps
   - Any open questions or blockers
3. Be specific with names, IDs, numbers, and stages — vague summaries are useless for continuity
4. Confirm to the user what was saved

This file is critical for the Account Manager workflow — with 400+ sellers, losing context between sessions means wasted time re-explaining situations.
